# Nodalix OS 0.6.2

A release for the apps: Archivador gets faster and easier to use, Brújula moves from 0.7 to
0.10 and Buzón, the Nodalia mail client, can be installed from the Store.

- **Archivador**: **Copy location** (Ctrl+Shift+C) puts the path of the selected item on the
  clipboard. Context menus that are taller than the window now scroll instead of hiding actions
  such as "Delete permanently". **Recent** is read off the main window thread and skips network
  mounts, so opening it no longer freezes the window.
- **Brújula 0.10.0** (was 0.7.0): the AI assistant can organise your tabs and run read-only
  scheduled tasks, and its settings slide over the conversation. Pages get find-in-page (Ctrl+F),
  zoom that is remembered per site, mute, screenshots and printing. Pinned tabs return to the page
  they were pinned on, the Library (Ctrl+H) gathers history, downloads, screenshots and archived
  tabs, and Zap hides any element of a page for good. The Spotlight answers quick searches and sums
  (`yt cats`, `2+2*3`), links that arrive from other apps open in a small window, and link rules
  send a site to a chosen space. Sites that need DRM are recognised and offered in an installed
  browser that carries Widevine. Checking for updates no longer fails with "http status: 403".
- **Buzón** is in the Nodalia view of the Store, so it installs and updates through NXPM like the
  other Nodalia apps. It is Buzón 0.1.8, which repairs the broken stylesheet of 0.1.6 and 0.1.7
  (transparent sidebar and cut-off panes) and the To, Cc and Bcc row of the composer.
- **Brújula updates on its own**: new versions of the browser reach Nodalix as signed packages
  without waiting for a full system release.
